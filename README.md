# assets

Static files referenced from [Quixotic](https://github.com/qxoticai/qxotic) READMEs and docs, kept
out of the main repository's history.

- `jam/bench-*.png`: benchmark charts drawn by `jam/docs/bench_plot.py` in the main repository
  (light and `-dark` variants).
- `toknroll/ground_truth_tokens.json`: the tiktoken golden truth the tokenizer tests read
  (text -> tokens for r50k, cl100k and o200k), generated by
  `toknroll/toknroll-benchmarks/generate_ground_truth.py` and fetched by `make test-fixtures`.

Link files as `https://raw.githubusercontent.com/qxoticai/assets/main/<path>`.
